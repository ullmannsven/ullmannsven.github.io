pyMOR
======
I contribute to [pyMOR](https://pymor.org) ([GitHub](https://github.com/pymor/pymor)), an open-source Python library for building model order reduction applications. My contributions include work on port-Hamiltonian reductors, low-rank ADI/RADI solvers and operator assembly and caching.

Research code
======
* [HKTR: Hermite kernel trust-region optimization](https://github.com/ullmannsven/A-Trust-Region-framework-for-optimization-using-Hermite-kernel-surrogate-models): reproduces all numerical experiments of the paper *A trust-region framework for optimization using Hermite kernel surrogate models*.
* [Model order reduction using group convolutional autoencoders](https://github.com/ullmannsven/Model-order-reduction-using-group-convolutional-autoencoders): code for my Master's thesis at the University of Münster.
